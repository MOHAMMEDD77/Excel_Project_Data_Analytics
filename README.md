# Excel Data Analytics Portfolio

Excel-based analysis and dashboard work focused on data job salaries, role comparisons, and the skills requested by employers in the data analytics and data science market.

## Project 1: Data Jobs Salary Dashboard

An interactive dashboard designed to help job seekers explore salary information for data-related roles.

**Focus:** Comparing salary information across job titles and presenting job-market information in an accessible dashboard.
